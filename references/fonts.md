# Font pairings by vibe

Each entry gives a heading/display font and a body font, both available on Google Fonts or close free substitutes.

| Vibe | Heading / Display | Body | Notes |
|---|---|---|---|
| Luxury | Canela / Playfair Display | Inter / Söhne | Serif display + clean grotesk body. Generous spacing, lots of whitespace. |
| Futuristic | Space Grotesk / Orbitron | Space Mono / Inter | Geometric, slightly technical. Monospace accents help reinforce the feel. |
| Modern / minimal | General Sans / Inter | Inter / Suisse Int'l | Low contrast and clean readability. |
| Elegant / editorial | Canela / Playfair Display | Lora / PT Serif | Magazine-like serif pairings. |
| Playful / friendly | Fraunces | Inter / Nunito Sans | Warm, rounded, less rigid. |
| Vintage / retro | Abril Fatface / Bebas Neue | Georgia / PT Serif | Slightly imperfect, nostalgic tone. |
| Bold / street / streetwear | Anton / Archivo Black | Inter / Archivo | High contrast, all-caps headings, strong attitude. |
| Organic / natural / wellness | Fraunces / Zodiak | Karla / Inter | Soft serif and earthy-feeling palette. |
| Corporate / professional | Inter | Inter | Deliberately plain and trustworthy. |
| Handmade / artisanal | Fraunces or a script accent | Inter / Karla | Use script sparingly — not for long blocks of copy. |

## How to apply

- Use one heading font and one body font per site.
- Load only 2–4 weights max per font for performance and clean consistency.
- If the site already has a font system, match it rather than guessing a new pairing.
- For admin interfaces, prefer a clean, restrained font even if the public-facing brand uses something more expressive.
