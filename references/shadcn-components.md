# shadcn/ui component catalog

This document captures the core set of patterns typically used for storefront and admin interfaces.

## Forms

- Button
- Input
- Textarea
- Select
- Checkbox
- Radio Group
- Switch
- Form wrapper with field validation

## Layout

- Card
- Separator
- Tabs
- Accordion
- Sidebar / Navigation Menu
- Pagination

## Feedback

- Alert
- Drawer
- Dialog
- Toast
- Progress
- Badge

## Data-heavy patterns

- Table
- Data table with sorting
- Filter bar
- Empty state
- Loading skeleton

## Usage guidance

Use a small set of components consistently, and prefer semantic structure over decorative wrappers. For admin work, tables and forms are usually more important than flashy animations.
