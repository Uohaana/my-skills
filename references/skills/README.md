# Skills Directory

This folder contains the reusable skill files for storefront, brand, and admin work.

## Categories

### Storefront
- `landing-page-kit-SKILL.md` — landing pages with hero sections, product storytelling, CTAs, and visual rhythm
- `about-page-kit-SKILL.md` — brand/story pages that match the rest of the site

### Admin
- `admin-panel-kit-SKILL.md` — login-gated admin dashboards and management pages
- `store-admin-kit-SKILL.md` — stock updates, reorder tracking, and order monitoring for store operations

### UI system
- `ui-styling-SKILL.md` — Tailwind and shadcn/ui patterns for clean, usable interfaces

## Usage guidelines

Use a skill when the task matches its scope:

- need a full landing page → `landing-page-kit-SKILL.md`
- need a matching about page → `about-page-kit-SKILL.md`
- need admin access and management screens → `admin-panel-kit-SKILL.md`
- need stock/order operational controls → `store-admin-kit-SKILL.md`
- need component and styling guidance → `ui-styling-SKILL.md`

## Notes

These skill files are intentionally focused and practical. They prefer:

- matching the current brand style when one exists
- clear user flows and real business logic
- restrained admin styling that favors usability over decoration
- real auth patterns where login-gated access is required
