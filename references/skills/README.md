# Skills Index

This folder contains the reusable Copilot skill files for storefront and admin workflows.

## Inventory

- `admin-panel-kit-SKILL.md` — build a gated admin account and management pages for a brand or store
- `store-admin-kit-SKILL.md` — narrow-focus stock and order admin system for store operations
- `about-page-kit-SKILL.md` — create an about page that matches an existing site's style and proportions
- `landing-page-kit-SKILL.md` — build a brand landing page with a hero, value props, CTA, and footer
- `ui-styling-SKILL.md` — UI design patterns using Tailwind and shadcn/ui

## Notes

These are intended to be used as prompt files or skill references for AI-assisted development. They usually assume the user wants a polished but practical storefront or back-office UI that matches the brand and works in the stack they already have.
