# Responsive design guide

Use mobile-first structure and expand to larger screens only when the layout becomes more readable.

## Common breakpoints

- `sm` — small screens
- `md` — tablet and small laptop
- `lg` — desktop layouts
- `xl` — larger desktop layouts

## Patterns

- Start with stacked mobile layouts
- Move to multi-column grid on wider screens
- Keep call-to-action buttons desktop-friendly but not oversized on mobile
- Prioritize text readability and comfortable tap targets

## Admin UI note

For dashboards and stock tables, a dense desktop layout is acceptable, but still keep mobile behavior reasonable if any admin access happens on the go.
