# Skills

Focused skill files for AI-assisted development. Each skill guides an agent to build a specific storefront or admin feature.

## By category

### Storefront
- `landing-page-kit.md` — landing pages with hero, value props, featured products, CTA
- `about-page-kit.md` — brand/story pages that match the site

### Admin
- `admin-panel-kit.md` — login-gated admin dashboards and management screens
- `store-admin-kit.md` — stock management and order tracking

### UI & System
- `ui-styling.md` — Tailwind and shadcn/ui patterns for beautiful, accessible interfaces

## How to use a skill

1. Pick the skill that matches your task
2. Copy its contents or share the filename with your AI agent
3. Provide context: existing design, brand colors, fonts, or vibe
4. Reference the supporting docs in `../references/` as needed

Each skill includes guidance on:
- Stack detection (plain HTML/CSS, React, Lovable, etc.)
- Design system matching (fonts, colors, spacing)
- Baseline page/feature structure
- Quality bar and practical conventions
